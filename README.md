# 菜鸟供应链需求预测分析

> 电商供应链需求预测项目 | Python + sklearn
> 业务目标：解决"仓库备多少货"的问题（减少库存积压与断货）

## 项目简介

基于阿里天池"菜鸟-需求预测与分仓规划"公开竞赛数据集（8,226条样本 × 419维特征），完成电商供应链商品需求量的**探索分析（EDA）**与**预测建模**，输出可辅助备货决策的需求预测方案。

## 业务问题

**仓库每天要备多少货？**
- 备多了 → 库存积压（压资金、占仓储）
- 备少了 → 断货（丢销售、客户投诉）

**解法**：用历史流量/成交/支付数据预测需求量，为备货提供依据。

## 数据说明

- 来源：阿里云天池公开竞赛数据（脱敏）
- 规模：8,226条样本 × 419维特征
- 核心字段：label（需求量）、item_id/store_code（商品店铺）、pv/uv/cart/gmv/alipay系列（流量/成交/支付特征，含1-14天滞后）

## 分析方法

### 1. 探索分析（EDA）
- 需求量分布 → 发现**长尾特征**（少量爆款贡献大部分需求）
- 特征相关性 → **支付类特征相关性最高**（num_alipay相关0.75）

### 2. 特征工程（核心步骤）
- 419维特征大量冗余（同一指标多滞后/多统计口径）
- 用相关性分析选取**Top30特征**，解决多重共线性

### 3. 预测建模
- 线性回归（基线）+ 随机森林（增强），80/20划分
- 评估：R² / RMSE

## 核心结果

| 指标 | 特征选择前 | 特征选择后 |
|------|-----------|-----------|
| 线性回归 R² | -0.449（失败）| **0.708** |
| 随机森林 R² | 0.714 | 0.702 |
| RMSE | - | ~105 |

**关键发现**：
1. **特征工程价值巨大**：仅靠特征选择，线性回归从-0.45提升到0.71
2. **支付类特征最重要**：历史支付数据是需求最强预测信号
3. **需求可预测性较强**：R²=0.7（需求预测业界普遍0.5-0.8）

## 业务建议

1. **区分备货策略**：爆款（高需求）重点备货，长尾商品按预测少量备货
2. **参考支付信号**：监控支付类指标提前调整备货
3. **模型可落地**：R²=0.7可作为备货决策辅助工具，减少人工经验判断
